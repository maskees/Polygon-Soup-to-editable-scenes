# Sample input data
Place 4 orthogonal images here:
- front.png
- back.png
- left.png
- right.png

You can generate test images from Objaverse:
1. Pick an object from https://objaverse.allenai.org/
2. Render 4 orthogonal views (front, back, left, right) at 512×512
3. Save as PNG in a subject directory (e.g., subject_001/)
